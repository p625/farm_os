# Roadmapa FarmOS Studio

## Studio v0.1 — Foundation

Cíl:

Editor se otevře přímo uvnitř hry.

Musí umět:

* přepnout mezi Game Mode a Studio Mode,
* zobrazit pracovní UI,
* načíst mapu,
* uložit mapu,
* zobrazit vrstvy.

Bez editace.

Pouze infrastruktura.

---

## Studio v0.2 — Selection

Přidat:

* výběr objektů,
* zvýraznění,
* inspektor,
* základní transformace,
* mazání.

---

## Studio v0.3 — Terrain

Možnost:

* měnit výšku terénu,
* vyhlazovat,
* malovat povrchy.

---

## Studio v0.4 — Roads

Editor cest.

Spline workflow.

Editace bodů.

---

## Studio v0.5 — Parcels

Nejdůležitější část.

* upravovat hranice,
* měnit ID,
* nastavovat typ,
* zobrazovat validaci.

## Studio v0.8 — Water

## Architecture

Editor musí být od začátku modulární.

Každý editor bude samostatný modul.

Například:

```text
Studio

├── Terrain Editor

├── Parcel Editor

├── Road Editor

├── Vegetation Editor

├── Water Editor

├── Building Editor

├── Validation

└── Export
```

Ale implementuj pouze infrastrukturu.
