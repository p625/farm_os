## Účel

Centralizovaný **index inspirace** — PureRef, Miro, fotobanky, interní screenshoty. Inspirace zde, pravidla v ostatních docs.

**[RULE]** Reference označovat `[INSPIRATION]`. Nikdy nekopírovat hex hodnoty nebo poly county z referencí do produkčních guides.

---

## Pravidla použití referencí

1. Každá reference má **tagy** (doména, sezóna, typ).
2. Reference **nejsou** acceptance criteria — slouží k diskusi a briefům.
3. Externí assety (500+ obrázků) žijí v DAM/PureRef — tento doc je **index**, ne úložiště.
4. Před použitím v outsource balíčku ověřit **licenci**.
