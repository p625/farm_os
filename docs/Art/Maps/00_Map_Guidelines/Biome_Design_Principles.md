## Účel

Principy pro **biomy a regionální varianty** napříč mapami. Map 01 realizuje biome *Střední Evropa — jemně zvlněná zemědělská krajina*.

**Nadřazené:** [ADR-A01 Framework](../../00_Strategy/ADR-A01_Regional_Identity_Framework.md), [Environment Bible](../../01_Domain_Bibles/Environment_Bible.md).

---

## Biom Map 01 (referenční)

| Parametr | Hodnota |
|----------|---------|
| Region | Střední Evropa (syntéza) |
| Reliéf | Jemně zvlněná nížina až podhůří |
| Zemědělství | Konvenční — obilí, řepka, kukuřice, louky |
| Les | Smíšený, remízky, aleje |
| Osídlení | Vesnice + samoty, bez města |

Budoucí mapy (Alpy, severní rovina, …) dostanou vlastní složku `Map_XX_*/` a biome sekci zde.
