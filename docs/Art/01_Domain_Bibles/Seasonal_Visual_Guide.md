## Účel

Hra je o sezónách. Jednotná pravidla jak vypadá **jaro / léto / podzim / zima** napříč terénem, vegetací, oblohou, props a UI ikonami.

**[RULE]** Palety sezón → [Color Script](../00_Strategy/Color_Script.md). Tento guide definuje **timing a checklisty**, ne duplikuje hex.

**Vazba:** World Rules (TBD) mění timing simulace → tento guide aktualizuje vizuální timing.
